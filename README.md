# ÉLIXIR & SOIE — Maison de Haute Beauté, Joaillerie & Couture

A high-end luxury e-commerce web application for beauty and fashion, curated with an opulent aesthetic inspired by the historic ateliers of Place Vendôme and Grasse, France.

---

## ✨ Luxury Aesthetic & Visual Identity

- **Color Palette**: Obsidian Noir (`#08080A`), Metallic Champagne & 24K Gold foil gradients (`#D4AF37`, `#F7E7C4`, `#997825`), and Alabaster / Pearl typography.
- **Haute Typography**: 
  - **Cinzel** & **Cormorant Garamond** for editorial, haute couture serif headings.
  - **Montserrat** for clean, letter-spaced luxury navigation and micro-labels.
- **Micro-Interactions**:
  - Smooth card elevation with gold edge glow on hover.
  - Secondary editorial angle reveal on product image hover.
  - Gold shimmer light sweep on primary call-to-actions.
  - Glassmorphic slide-over drawers with backdrop blurs for the Shopping Bag and Private Wishlist.
  - Floating luxury toast notifications for instant client feedback.

## 🚀 Key Interactive Features

- **Dynamic Multi-Currency Switcher**: Real-time conversion across **USD ($)**, **EUR (€)**, **GBP (£)**, **AED (د.إ)**, and **JPY (¥)**.
- **Interactive Shopping Bag Drawer**:
  - Add to bag with custom quantity controls.
  - Free White-Glove Courier Delivery progress tracker ($300 threshold).
  - Subtotal and total computation with instant updates.
  - LocalStorage persistence (cart remains intact on page refresh).
- **Private Wishlist Drawer**:
  - One-click heart toggle on every creation.
  - Dedicated wishlist slide-over panel with direct "Move to Bag" capability.
- **Product Quick View Modal**:
  - Multi-angle photo gallery with interactive thumbnail switching.
  - Quantity adjuster, full editorial description, and craftsmanship notes.
  - Inclusions breakdown and direct VIP acquisition button.
- **Real-Time Live Search Overlay**: Instant search matching creation names, categories, and ingredients.
- **VIP Private Salon Consultation Booking**: Modal booking system for bridal styling, high jewelry viewings, or skincare diagnoses.
- **Simulated White-Glove Checkout**: Full acquisition form with client address and unique Order Reference code generation.
- **Private Salon Newsletter**: Instant welcome courtesy code (`PRIVEE2026`) upon email registration.
